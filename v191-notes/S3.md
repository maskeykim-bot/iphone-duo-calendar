### キーボードの ∧∨✓ の帯（入力補助バー）を消す
- `@capacitor/keyboard@8.0.6`（`@capacitor/core` 8.6.2 に合う版）を入れた（`npm install @capacitor/keyboard@8.0.6`）。`npm run ios`（build:www と `cap sync ios`）が **Linux で最後まで通り**、`ios/App/CapApp-SPM/Package.swift` に `CapacitorKeyboard`（`../../../node_modules/@capacitor/keyboard`）が入り、`ios/App/App/capacitor.config.json` の `packageClassList` に `KeyboardPlugin` が登録された。失敗した部分はなし（Xcode でのビルド・実機は未確認）。
- 起動時（`initNative`）に `hideKeyboardAccessoryBar()`（js/native.js）：`Capacitor.isNativePlatform()` が true のときだけ、`window.Capacitor.Plugins.Keyboard.setAccessoryBarVisible({ isVisible:false })`、なければ `nativePromise('Keyboard','setAccessoryBarVisible',…)`。Web では何もしない。reject・同期の例外とも外へ出さない。
- **resize は "none"**（capacitor.config.json の `plugins.Keyboard.resize`）。プラグインの既定は `native` で、キーボードが出るたびに WKWebView の枠を縮める（`_updateFrame`）。今の kbTop の作り（`visualViewport` の `offsetTop+height` と、最大の高さ `L.h` からの差）を壊さないよう、WebView の大きさを変えない "none" にした（"none" のときプラグインは `contentInset` を 0 に戻すだけ）。プラグインは `load` で補助バーを隠す（`hideFormAccessoryBar = YES`）ので、JS の呼び出しは念押し。
- **補助バーの分を自分で足し引きしていないか**：js・css を `補助バー／accessory／44〜56` で調べ、足し引きは**なかった**（補助列＝`ASSIST_HIT 44` はタスクのチップの列で別物。書式シートの `216+34` はキーボードの高さの既定で別物）。入力欄・シート下端は `kbTop−8`（`--vb`＋8、`computeKbLayout` の `ADD_GAP 8`）で、固定の y は無い。
- ノートのシート：キーボードが出ているとき、シート内の本文の窓の下端が kbTop−8 になるよう `padding-bottom:8`（`--ns-pb`）を足した（シートの下端は kbTop のまま）。

## 直せなかった点・判断
